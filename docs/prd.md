# 부산 AI·DX 지원사업 문의 포털 PRD

## 1. 목적

부산 AI·DX 지원사업 문의 포털은 지역기업과 시민이 부산정보산업진흥원의 지원사업에 대해 문의를 남기고, 등록된 문의를 한 화면에서 확인·삭제·엑셀 관리할 수 있는 단일 페이지 웹서비스이다.

이 페이지는 서버 저장소 없이 브라우저 메모리에서 문의 데이터를 임시 관리한다. 사용자가 새 문의를 등록하면 즉시 문의 목록의 최상단에 추가되어야 하며, 페이지를 새로고침하면 기본 샘플 문의 목록으로 되돌아간다.

완성된 화면은 다음 작업을 지원해야 한다.

- 지원사업 문의 작성
- 등록된 문의 목록 확인
- 문의 건수 확인
- 문의 삭제
- 엑셀 파일에서 문의 가져오기
- 현재 문의 목록을 엑셀 파일로 내보내기

## 2. 사용자

주 사용자는 부산정보산업진흥원의 지원사업에 관심 있는 지역기업 담당자, 예비창업자, 스타트업 관계자, 교육 신청 희망자, 일반 시민이다.

사용자는 웹페이지에 접속해 별도의 로그인 없이 문의를 작성할 수 있어야 한다. 사용자는 문의 등록 전 카테고리를 선택하고, 이름·제목·내용을 입력한다.

운영자 또는 담당자는 같은 화면에서 등록된 문의 목록을 확인하고, 불필요한 문의를 삭제하거나, 문의 데이터를 엑셀 파일로 가져오고 내보낼 수 있어야 한다.

## 3. 핵심 기능

### 문의 작성

사용자는 상단의 "문의 작성" 영역에서 문의를 등록한다. 이 영역의 우측 상단에는 "메모리 임시 등록" 문구가 표시되어 현재 등록 방식이 임시 저장임을 보여준다.

문의 작성 폼은 다음 입력 항목을 포함한다.

- 카테고리: 선택형 필드
- 이름: 한 줄 텍스트 입력
- 제목: 한 줄 텍스트 입력
- 내용: 여러 줄 텍스트 입력

카테고리 선택 항목은 다음 7개를 제공한다.

- AI·DX 솔루션 도입
- 데이터·클라우드 바우처
- 교육·인재양성 신청
- 스타트업 입주·창업
- 게임·콘텐츠 제작 지원
- 해외진출
- 기타

카테고리의 기본 선택값은 "AI·DX 솔루션 도입"이다.

이름 입력란에는 "예: 김부산" 안내 문구가 표시된다. 제목 입력란에는 "문의 제목을 입력하세요" 안내 문구가 표시된다. 내용 입력란에는 "지원사업 문의 내용을 입력하세요" 안내 문구가 표시된다.

카테고리, 이름, 제목, 내용은 모두 필수 입력 항목이다. 사용자가 "등록하기" 버튼을 누르면 입력값 앞뒤 공백을 제거한 뒤 문의 목록에 추가한다. 제목, 이름, 내용 중 하나라도 비어 있으면 문의를 추가하지 않는다.

문의가 정상 등록되면 작성 폼은 초기화되고, 새 문의는 문의 목록의 가장 위에 표시된다. 새 문의의 작성 시각은 등록 버튼을 누른 시점으로 기록되며, 목록에는 "방금"으로 표시된다.

### 문의 목록

문의 목록 영역의 제목은 "문의 목록"으로 표시한다. 제목 아래에는 현재 목록의 전체 문의 수를 "총 N건" 형식으로 표시한다.

초기 화면에는 샘플 문의 5건을 표시한다. 최신 문의가 위에 오도록 작성 시각 기준 내림차순으로 정렬한다.

초기 샘플 문의는 다음 순서와 내용을 가진다.

| 카테고리 | 제목 | 작성자 | 내용 | 상대 시간 |
| --- | --- | --- | --- | --- |
| 교육·인재양성 신청 | AI 활용 교육과정 일정 안내 부탁드립니다 | 정하윤 | AI 활용 기초 교육과정과 실무형 교육과정의 개설 일정, 신청 방법을 안내받고 싶습니다. | 1분 전 |
| 게임·콘텐츠 제작 지원 | Bu:Star 게임 제작비 신청 절차 | 박도현 | Bu:Star 게임콘텐츠 제작 지원사업의 신청 절차와 제출 서류, 평가 기준이 궁금합니다. | 3분 전 |
| 스타트업 입주·창업 | 센텀 스타트업 입주 자격 문의 | 이서연 | 센텀 지역 창업지원 공간 입주 대상과 예비창업자 신청 가능 여부를 확인하고 싶습니다. | 8분 전 |
| 데이터·클라우드 바우처 | 데이터 바우처 신청 기간이 언제인가요? | 최민준 | 올해 데이터 바우처와 클라우드 바우처 신청 접수 기간, 선정 발표 일정을 알고 싶습니다. | 14분 전 |
| AI·DX 솔루션 도입 | AI 솔루션 실증 비용 지원 가능한가요? | 김지우 | 지역 제조기업에서 AI 품질검사 솔루션을 실증하려고 합니다. PoC 비용 지원이 가능한 사업이 있는지 문의드립니다. | 22분 전 |

각 문의는 하나의 흰색 카드로 표시한다. 카드 안에는 다음 정보가 포함되어야 한다.

- 카테고리 배지
- 작성 후 경과 시간
- 문의 제목
- 작성자
- 삭제 버튼
- 문의 내용

작성자는 "작성자 이름" 형식으로 표시한다. 예를 들어 작성자가 "정하윤"이면 "작성자 정하윤"으로 표시한다.

경과 시간은 현재 시각과 작성 시각의 차이를 기준으로 다음 형식으로 표시한다.

- 1분 미만: "방금"
- 1분 이상 60분 미만: "N분 전"
- 1시간 이상 24시간 미만: "N시간 전"
- 24시간 이상: "N일 전"

경과 시간 표시는 30초마다 갱신되어야 한다.

### 문의 삭제

각 문의 카드의 오른쪽에는 "삭제" 버튼을 표시한다. 사용자가 삭제 버튼을 누르면 해당 문의를 목록에서 즉시 제거한다.

삭제 후 문의 목록은 다시 최신순으로 표시되며, 문의 건수도 즉시 갱신된다. 삭제 전 확인 모달은 표시하지 않는다.

### 엑셀 가져오기

문의 목록 제목 영역 오른쪽에는 "엑셀 가져오기" 버튼을 표시한다. 사용자가 버튼을 누르면 파일 선택 창이 열려야 한다.

가져올 수 있는 파일 형식은 `.xlsx`, `.xls`, `.csv`이다. 사용자가 파일을 선택하면 첫 번째 시트의 데이터를 읽어 문의 목록에 추가한다.

가져오기 데이터는 다음 열 이름을 인식해야 한다.

| 문의 필드 | 인식 가능한 열 이름 |
| --- | --- |
| 카테고리 | 카테고리, category |
| 제목 | 제목, title |
| 작성자 | 작성자, 이름, author, name |
| 내용 | 내용, content |
| 작성일 | 작성일, createdAt, created_at |

카테고리, 제목, 작성자, 내용 중 하나라도 비어 있는 행은 가져오지 않는다. 작성일이 없거나 날짜로 해석할 수 없는 경우에는 가져오기 시점의 현재 시각을 작성 시각으로 사용한다.

가져온 문의는 기존 문의보다 위에 추가한다. 가져오기 완료 후 문의 목록과 문의 건수를 즉시 갱신한다.

엑셀 상태 문구는 문의 목록 조작 버튼 아래에 표시한다. 성공 시에는 "N건을 엑셀에서 가져왔습니다."라고 표시한다.

가져올 수 있는 문의 데이터가 없으면 "가져올 수 있는 문의 데이터가 없습니다. 카테고리, 제목, 작성자, 내용 열을 확인해 주세요."라고 표시한다.

파일 읽기 중 오류가 발생하면 "엑셀 파일을 읽는 중 문제가 발생했습니다."라고 표시한다.

### 엑셀 내보내기

문의 목록 제목 영역 오른쪽에는 "엑셀 내보내기" 버튼을 표시한다. 이 버튼은 "엑셀 가져오기" 버튼 오른쪽에 배치한다.

사용자가 "엑셀 내보내기" 버튼을 누르면 현재 문의 목록을 최신순으로 정렬해 엑셀 파일로 다운로드한다.

내보내기 파일명은 `busan-dx-inquiries-YYYY-MM-DD.xlsx` 형식이다. `YYYY-MM-DD`는 내보내기를 실행한 날짜이다.

엑셀 파일에는 "문의목록" 시트 하나를 생성한다. 각 행은 문의 1건을 나타내며 다음 열을 포함한다.

- 번호
- 카테고리
- 제목
- 작성자
- 내용
- 작성일

작성일은 날짜와 시간을 포함하는 값으로 저장하고, 표시 형식은 `yyyy-mm-dd hh:mm`으로 설정한다.

엑셀 열 너비는 다음 기준으로 설정한다.

- 번호: 8
- 카테고리: 22
- 제목: 34
- 작성자: 14
- 내용: 60
- 작성일: 22

내보내기 성공 후 엑셀 상태 문구에 "N건을 엑셀 파일로 내보냈습니다."라고 표시한다.

문의가 하나도 없을 때 내보내기 버튼을 누르면 파일을 만들지 않고 "내보낼 문의가 없습니다."라고 표시한다.

## 4. 화면 구성

페이지는 하나의 세로형 화면으로 구성한다. 전체 콘텐츠는 화면 중앙에 배치하고, 최대 너비는 약 1024px 수준으로 제한한다. 좌우 여백은 모바일에서 16px, 작은 태블릿 이상에서 24px 이상 확보한다. 상단과 하단에는 충분한 여백을 두어 흰 배경 위에 콘텐츠가 안정적으로 보이게 한다.

### 헤더 영역

화면 최상단에는 헤더 영역을 배치한다. 헤더 하단에는 옅은 회색 구분선을 표시한다.

헤더에는 다음 요소를 위에서 아래 순서로 표시한다.

- 기관 배지: "부산정보산업진흥원"
- 페이지 제목: "부산 AI·DX 지원사업 문의 포털"
- 설명 문구: "지역기업·시민 누구나 부산정보산업진흥원의 지원사업에 문의할 수 있는 창구입니다."

기관 배지는 연한 하늘색 배경의 작은 라벨로 표시한다. 페이지 제목은 화면에서 가장 큰 글자이며 진한 남색 또는 거의 검정에 가까운 색으로 표시한다. 설명 문구는 제목 아래에 배치하고, 본문보다 옅은 회색 계열로 표시한다.

### 문의 작성 영역

헤더 아래에는 문의 작성 영역을 배치한다. 이 영역은 연한 회청색 배경의 카드 형태이며, 1px 회색 테두리와 약한 그림자를 가진다.

문의 작성 영역 상단에는 왼쪽에 "문의 작성" 제목을, 오른쪽에 "메모리 임시 등록" 보조 문구를 표시한다.

폼의 첫 번째 줄은 데스크톱에서 2열로 배치한다. 왼쪽에는 카테고리 선택 필드, 오른쪽에는 이름 입력 필드를 둔다. 모바일에서는 두 필드를 위아래로 배치한다.

그 아래에는 제목 입력 필드를 한 줄 전체 너비로 배치한다. 제목 아래에는 내용 입력 필드를 한 줄 전체 너비로 배치한다. 내용 입력 필드는 기본 높이가 약 5줄이며, 사용자가 세로로 크기를 조절할 수 있다.

폼 하단에는 "등록하기" 버튼을 오른쪽 정렬로 배치한다. 버튼은 진한 파란색 배경과 흰색 글자를 사용한다.

### 문의 목록 영역

문의 작성 영역 아래에는 16px 정도의 간격을 두고 문의 목록 영역을 배치한다.

문의 목록 상단은 왼쪽 정보 영역과 오른쪽 버튼 영역으로 나뉜다.

왼쪽 정보 영역에는 "문의 목록" 제목과 그 아래 "총 N건" 문구를 표시한다.

오른쪽 버튼 영역에는 "엑셀 가져오기" 버튼과 "엑셀 내보내기" 버튼을 가로로 배치한다. 모바일에서는 줄바꿈이 가능해야 하며 버튼 간 간격은 일정하게 유지한다.

버튼 아래에는 엑셀 상태 문구를 표시할 수 있는 한 줄 영역을 둔다. 상태 문구가 없을 때도 목록과의 간격이 어색하지 않아야 한다.

문의 카드 목록은 세로로 나열하며 카드 사이에는 16px 정도의 간격을 둔다.

### 문의 카드

각 문의 카드는 흰색 배경, 1px 옅은 회색 테두리, 약한 그림자를 가진다. 모서리는 8px 반경으로 둥글게 처리한다. 카드 내부 여백은 16px 정도로 설정한다.

카드 상단은 데스크톱에서 좌우 구조로 배치한다. 왼쪽에는 문의 정보, 오른쪽에는 삭제 버튼을 배치한다. 모바일에서는 삭제 버튼이 정보 아래로 내려가도 되며, 카드 안의 요소들이 서로 겹치면 안 된다.

문의 정보의 첫 줄에는 카테고리 배지와 상대 시간을 나란히 표시한다. 카테고리 배지는 연한 하늘색 배경과 진한 파란색 글자를 사용한다. 상대 시간은 작은 회색 글자로 표시한다.

그 아래에는 문의 제목을 굵게 표시한다. 제목은 긴 단어가 있어도 카드 밖으로 넘치지 않고 줄바꿈되어야 한다.

제목 아래에는 작성자를 작은 회색 굵은 글자로 표시한다.

카드 하단에는 문의 내용을 표시한다. 내용은 제목·작성자 영역과 약간의 위 간격을 두고 표시하며, 줄 간격을 넉넉하게 둔다. 긴 내용은 카드 너비 안에서 자동 줄바꿈되어야 한다.

삭제 버튼은 흰색 배경, 회색 테두리, 회색 글자를 기본 상태로 가진다. 마우스를 올리면 테두리와 글자가 진한 파란색으로 바뀐다.

## 5. 디자인 규칙

전체 페이지 배경은 흰색으로 유지한다. 텍스트 기본 색상은 어두운 회청색 계열을 사용한다.

주요 색상은 다음 기준을 따른다.

- 기본 파란색: `#1E40AF`
- 보조 하늘색: `#0EA5E9`
- 연한 영역 배경: `#F8FAFC`
- 가장 진한 제목 색상: slate-950 수준의 거의 검정색
- 본문 색상: slate-700 또는 slate-800 수준의 회청색
- 보조 문구 색상: slate-500 또는 slate-600 수준의 회색
- 테두리 색상: slate-200 또는 slate-300 수준의 옅은 회색

폰트는 Pretendard를 우선 사용하고, 사용할 수 없는 경우 Noto Sans KR, 시스템 sans-serif 순서로 대체한다.

기본 본문 글자 크기는 15px 수준이다. 주요 제목은 24px 이상, 넓은 화면에서는 30px 수준까지 커진다. 섹션 제목은 약 18px, 카드 제목은 약 16px, 보조 문구와 버튼은 약 14px로 표시한다.

모든 카드, 입력 필드, 버튼, 배지는 8px 모서리 반경을 사용한다.

입력 필드의 높이는 한 줄 입력과 선택 필드 기준 약 44px이다. 입력 필드는 흰색 배경, 회색 테두리, 내부 좌우 여백을 가진다. 포커스 상태에서는 진한 파란색 테두리와 옅은 파란색 포커스 링을 표시한다.

버튼은 명확한 상태 변화를 가져야 한다.

- "등록하기" 버튼: 기본 상태는 진한 파란색 배경과 흰색 글자, 호버 상태는 더 어두운 파란색 배경
- "엑셀 가져오기" 버튼: 기본 상태는 흰색 배경, 회색 테두리, 어두운 회색 글자, 호버 상태는 파란색 테두리와 파란색 글자
- "엑셀 내보내기" 버튼: 기본 상태는 거의 검정색 배경과 흰색 글자, 호버 상태는 진한 파란색 배경
- "삭제" 버튼: 기본 상태는 흰색 배경, 회색 테두리, 회색 글자, 호버 상태는 파란색 테두리와 파란색 글자

사용자가 직접 입력하거나 엑셀에서 가져온 텍스트는 화면에 표시될 때 HTML로 실행되지 않아야 한다. 예를 들어 `<script>` 같은 문자열을 입력해도 코드가 실행되지 않고 텍스트로 표시되어야 한다.

반응형 동작은 다음 기준을 따른다.

- 모바일에서는 모든 주요 영역이 단일 열로 쌓인다.
- 데스크톱에서는 카테고리와 이름 입력 필드가 2열로 배치된다.
- 데스크톱에서는 문의 카드 상단의 정보와 삭제 버튼이 좌우로 배치된다.
- 버튼 영역은 화면이 좁을 때 줄바꿈되어야 하며, 버튼 텍스트가 잘리거나 겹치면 안 된다.
- 긴 제목, 작성자명, 내용은 카드 밖으로 넘치지 않고 줄바꿈되어야 한다.

## 6. 성공 기준

페이지에 접속하면 헤더, 문의 작성 영역, 문의 목록 영역이 모두 한 화면 흐름 안에서 보인다.

초기 문의 목록에는 샘플 문의 5건이 최신순으로 표시되고, 문의 목록 제목 아래에는 "총 5건"이 표시된다.

사용자가 카테고리, 이름, 제목, 내용을 입력하고 "등록하기"를 누르면 새 문의가 목록 최상단에 추가되고, 문의 건수가 1 증가하며, 작성 시간은 "방금"으로 표시된다.

사용자가 필수 입력값 없이 등록을 시도하면 빈 문의 카드가 생성되지 않는다.

사용자가 문의 카드의 "삭제" 버튼을 누르면 해당 카드가 즉시 사라지고, 문의 건수가 1 감소한다.

상대 시간 표시는 등록 직후 "방금"으로 시작하고, 시간이 지나면 "N분 전", "N시간 전", "N일 전" 형식으로 바뀐다.

사용자가 `.xlsx`, `.xls`, `.csv` 파일을 가져오면 유효한 문의 행만 목록 상단에 추가되고, 성공 또는 실패 상태 문구가 버튼 아래에 표시된다.

사용자가 "엑셀 내보내기"를 누르면 현재 문의 목록이 `busan-dx-inquiries-YYYY-MM-DD.xlsx` 파일로 저장되고, 파일 안에는 "문의목록" 시트와 번호·카테고리·제목·작성자·내용·작성일 열이 포함된다.

문의가 없는 상태에서 내보내기를 누르면 파일이 생성되지 않고 "내보낼 문의가 없습니다." 문구가 표시된다.

모바일과 데스크톱 화면 모두에서 입력 필드, 버튼, 문의 카드의 텍스트가 겹치거나 잘리지 않는다.

사용자가 특수문자나 HTML 태그가 포함된 문의를 등록해도 화면에는 안전한 텍스트로 표시된다.
